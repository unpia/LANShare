# LANShare — локальный файлообменник для Windows

Десктопное приложение (Python + customtkinter) для передачи файлов и папок между
компьютерами **в одной Wi-Fi/LAN сети**. Работает **без интернета**, **без авторизации**
и **без серверной части**: устройства находят друг друга автоматически через
UDP-broadcast, данные идут напрямую по TCP с буфером 1 МБ (без искусственных
ограничений скорости).

* Порт поиска устройств: **UDP 50505** · Порт передачи: **TCP 50506**
* Готовая сборка: `dist\LANShare.exe` (запуск двойным кликом, Python не требуется)

## 1. Условия запуска

| Требование | Значение |
|---|---|
| Операционная система | **Windows 10 или Windows 11** (x64). Linux/macOS не поддерживаются (`os.startfile`, сборка `.exe`) |
| Сеть | Оба компьютера подключены к **одной локальной сети / одной Wi-Fi сети** (одна подсеть, например `192.168.0.x`) |
| Интернет | **Не требуется** и не используется |
| Учётная запись | **Не требуется** — авторизации и регистрации нет |
| Python | **Не требуется** для `dist\LANShare.exe`. Нужен только для запуска из исходников (Python 3.10+) |
| Брандмауэр | На **обоих** ПК должно быть разрешено входящее подключение для LANShare (порты UDP 50505, TCP 50506) |
| Права | Обычные права пользователя; права администратора нужны только для ручного создания правила брандмауэра |

> Устройства, находящиеся в **разных подсетях** (например, один в гостевой сети Wi-Fi,
> другой в основной), друг друга не увидят — это ограничение широковещательного поиска.

## 2. Первый запуск и настройка Брандмауэра Windows

1. Скопируйте `LANShare.exe` на оба компьютера и запустите двойным кликом.
   При запуске из исходников: `pip install -r requirements.txt`, затем `python main.py`.

2. **Сразу после запуска Windows покажет окно**
   «Брандмауэр Защитника Windows заблокировал некоторые функции приложения».

   * Нажмите **«Разрешить доступ»**.
   * Обязательно поставьте **обе** галочки: **«Частные сети»** и **«Общедоступные сети»**.

   Если нажать «Отмена», приложение запустится, но **не найдёт другие компьютеры**
   и **не примет входящие файлы**.

3. Если окно было закрыто случайно, исправьте это одним из способов:

   * Панель управления → «Брандмауэр Защитника Windows» → «Разрешить работу с приложением
     через брандмауэр Защитника Windows» → найдите `LANShare.exe` (или `python.exe`, если
     запускаете из исходников) → включите галочки для частных и общедоступных сетей.
   * Либо в PowerShell **от имени администратора**:

     ```powershell
     New-NetFirewallRule -DisplayName "LANShare UDP" -Direction Inbound -Protocol UDP -LocalPort 50505 -Action Allow
     New-NetFirewallRule -DisplayName "LANShare TCP" -Direction Inbound -Protocol TCP -LocalPort 50506 -Action Allow
     ```

4. **Проверка:** запустите приложение на втором компьютере. В левой панели
   «Устройства в сети» в течение 2–4 секунд появится карточка с именем и IP второго ПК.
   Если карточка появилась на обеих сторонах — сеть настроена правильно.

5. **Настройте себя (левая панель):**

   * поле **«Ваш ник»** → введите имя (например, `PC-Anna`) → кнопка **«Применить»**;
   * кнопка **«Выбрать папку»** → папка, куда будут сохраняться входящие файлы
     (по умолчанию — `Downloads` текущего пользователя);
   * чекбокс **«Принимать все файлы автоматически»** — см. раздел 5.

## 3. Сценарий: отправка файла

1. В левой панели **кликните по нужному устройству** — карточка подсветится синим,
   сверху справа появится надпись `Получатель: <Имя> (<IP>)`.
2. Нажмите **«Отправить файлы»** и выберите один или **сразу несколько файлов**
   (в окне выбора удерживайте `Ctrl` или `Shift`).
3. У получателя появится окно:
   «Пользователь **[Имя] ([IP]**) хочет отправить **[Название]** (**[Размер]**)» с кнопками
   **«Принять»** и **«Отклонить»**.
4. После нажатия «Принять» в правой панели **«История передач»** появится строка
   с прогресс-баром, процентом, скоростью в МБ/с и статусом.
5. По завершении статус станет «Готово · Отправлено в …», а кнопка
   **«Открыть папку»** откроет Проводник Windows на папке с файлом (у получателя — на папке,
   куда файл сохранён).

## 4. Сценарий: отправка папки

1. Выберите устройство в левой панели.
2. Нажмите **«Отправить папку»** и выберите каталог (любой уровень вложенности).
3. Папка **автоматически упаковывается во временный `.zip` без сжатия** (`ZIP_STORED`) —
   это происходит мгновенно и не нагружает процессор. В истории на этот момент
   отображается этап «Упаковка папки в .zip…».
4. У получателя — то же окно подтверждения, что и для файла.
5. Архив передаётся, у получателя **автоматически распаковывается** в папку сохранения,
   после чего временный `.zip` удаляется (и на отправителе, и на получателе).
   Структура вложенных папок и пустые папки сохраняются.

## 5. Настройка автоприёма и папки загрузки

| Настройка | Где находится | Поведение |
|---|---|---|
| **Папка сохранения** | Левая панель → «ПАПКА СОХРАНЕНИЯ» → «Выбрать папку» | Все входящие файлы и распакованные папки сохраняются сюда. По умолчанию — `Downloads` пользователя |
| **Автоприём** | Чекбокс «Принимать все файлы автоматически» | Диалоги подтверждения не показываются, файлы принимаются автоматически. **Если файл с таким именем уже есть, он сохраняется копией** `имя (1).ext` — перезаписи без вашего участия не происходит |
| **Ник** | Левая панель → «ВАШ НИК» + «Применить» | Имя, которое видят другие устройства в списке и в окне подтверждения |

Настройки сохраняются автоматически и восстанавливаются при следующем запуске
(файл `%USERPROFILE%\.lanshare\config.json`).

**Защита от перезаписи (при выключенном автоприёме).** Если файл или папка с таким именем
уже есть в папке сохранения, после нажатия «Принять» появится диалог:

> «Файл «имя» уже существует. Вы точно хотите скачать его ещё раз?»
> кнопки: **«Перезаписать»** · **«Сохранить как копию»** (`имя (1).ext`) · **«Отмена»**

## 6. Типовые ошибки и способы их решения

| Симптом | Причина | Решение |
|---|---|---|
| **Устройство не отображается в списке** | Брандмауэр Windows блокирует UDP 50505 | Разрешите доступ для `LANShare.exe`/`python.exe` в частных **и** общедоступных сетях (раздел 2), либо создайте правило `New-NetFirewallRule` для UDP 50505 |
| Устройство не отображается | Компьютеры в разных подсетях или разных сетях Wi-Fi (гостевая сеть, VPN) | Отключите VPN, подключите оба ПК к одной сети; проверьте, что IP выглядят как `192.168.x.x` одной подсети |
| Устройство не отображается | На роутере включена **изоляция клиентов** (AP Isolation / Client Isolation) | Отключите изоляцию в настройках роутера — при её включении обмен между клиентами сети запрещён на уровне оборудования |
| Устройство не отображается | На втором ПК приложение не запущено или уже закрыто | Запустите LANShare на втором ПК; помните, что устройство исчезает из списка через ~6 секунд после его закрытия |
| **Входящие файлы не приходят** («Передача не удалась», `WinError 10054`/`10061`) | Брандмауэр блокирует входящий TCP 50506 | Разрешите TCP 50506 для LANShare (раздел 2); проверьте, что приложение получателя ещё запущено |
| **Низкая скорость по Wi-Fi 2.4 ГГц** (2–8 МБ/с) | Диапазон 2.4 ГГц перегружен, реальная пропускная способность 20–70 Мбит/с | Подключите оба ПК к Wi-Fi **5 ГГц** или кабелем (Ethernet, 100 Мбит/с ≈ 11 МБ/с, 1 Гбит/с ≈ 100+ МБ/с). На 5 ГГц и по кабелю приложение выдаёт близкую к пределу сети скорость |
| Скорость падает в конце передачи большой папки | Распаковка архива на диске получателя | Это ожидаемо: после приёма данных статус меняется на «Готово». Используйте SSD или уменьшите число мелких файлов |
| **Антивирус блокирует запуск `.exe`** | Ложное срабатывание на однофайловую сборку PyInstaller (эвристика) | Добавьте `dist\LANShare.exe` в исключения антивируса; либо запустите из исходников: `python main.py`. Сборка выполняется локально из `build.py`, сторонних загрузок нет |
| «Не удалось открыть порт 50505/50506» в статус-баре | Порт занят другим приложением или вторым экземпляром LANShare | Закройте второй экземпляр приложения или приложение, занимающее порт (проверить: `netstat -ano \| findstr 5050`) |
| Приложение не запускается / сразу закрывается | Ошибка при старте (для `.exe` — из-за отсутствия ресурсов или прав) | Откройте файл `%USERPROFILE%\.lanshare\error.log` — там стек ошибки |
| Кнопка «Открыть папку» неактивна | Передача ещё не завершена или завершилась ошибкой | Кнопка активируется только для успешно завершённых передач |
| Файл сохранён как `имя (1).ext` вместо `имя.ext` | Сработала защита от перезаписи/автоприём с существующим именем | Это ожидаемое поведение: чтобы не потерять данные, создаётся копия. Удалите ненужный файл или выберите «Перезаписать» при ручном приёме |

## 7. Запуск из исходников и сборка `.exe`

```powershell
# запуск из исходников (нужен Python 3.10+)
pip install -r requirements.txt
python main.py

# сборка одного автономного файла dist\LANShare.exe
python build.py
```

`build.py` сам находит каталог установленного `customtkinter` и добавляет его в сборку
через `--add-data` (без этого собранный `.exe` не находит темы и шрифты), собирает файл
с флагами `--noconsole --onefile --name LANShare` и печатает путь к результату.
Готовый `.exe` запускается двойным кликом без установленного Python и без окна консоли.

## 8. Где хранятся данные

| Что | Путь |
|---|---|
| Настройки и история передач | `%USERPROFILE%\.lanshare\config.json` (ник, папка сохранения, флаг автоприёма, ID устройства, последние 300 записей истории) |
| Журнал ошибок запуска | `%USERPROFILE%\.lanshare\error.log` |
| Принятые файлы | Выбранная папка сохранения (по умолчанию `Downloads`) |
| Временные архивы папок | Системная временная папка (отправитель) и папка сохранения (получатель) — удаляются автоматически |

## 10. Ограничения версии 1.0

* Работа только в пределах одной подсети; интернет, VPN и разные сети не поддерживаются.
* Передача без шифрования — приложение рассчитано на доверенную локальную сеть.
* Докачка прерванной передачи не реализована: при обрыве передачу нужно запустить заново.
* Поддерживается только Windows; клиентов для мобильных устройств и веб-версии нет.
